快速连接
dsh web

在终端运行上述命令，启动后 DSH 将输出包含 Token 的访问链接（如 http://127.0.0.1:3080/?token=...）。请直接复制该链接粘贴到下方并点击「立即连接」，本插件将自动兑换并保存长期 Cookie 凭据。

配套 Cordis 桥接插件（可选）
dsh web --patch ./bridge/cordis.yml

若需在智能手表上实时弹出卡片审批工具权限与交互提问，可使用上述 --patch 参数加载内置的伴侣桥接插件（位于 bridge/dsh-hydro-bridge.ts，无需侵入修改 DSH 源码）。
